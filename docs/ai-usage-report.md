

# AI Usage Report

## Tools Used & Use Cases

### ChatGPT

I used ChatGPT as an AI-assisted development tool throughout this assignment. I mainly used it for guidance, explanations, code suggestions, debugging, and documentation support.

I used ChatGPT for the following tasks:

- Organizing the portfolio into the required About Me, Projects, and Contact sections.
- Suggesting HTML structure and explaining semantic HTML elements.
- Creating and improving CSS for the light blue and grey design of the portfolio.
- Implementing responsive design using Flexbox, CSS Grid, and media queries.
- Helping debug an issue where the project images were being cropped when the browser window became smaller.
- Explaining HTML form validation using `required` and `type="email"`.
- Adding JavaScript interaction to the contact form.
- Explaining how the JavaScript code works instead of only providing the code.
- Assisting with the organization and wording of the technical documentation and README.

## Benefits & Challenges

### Benefits

Using ChatGPT helped me understand how different parts of a front-end web application work together. Instead of searching separately for every HTML, CSS, or JavaScript concept, I could ask questions about the specific problem I was facing.

It was especially useful when working on responsive design. For example, when I noticed that the project images became cropped as the browser window became smaller, ChatGPT helped identify that `object-fit: cover` was causing the issue. I changed it to `object-fit: contain` and tested the website again. This kept the complete images visible on smaller screens.

ChatGPT also helped explain concepts such as CSS Grid, Flexbox, media queries, HTML form validation, and JavaScript event listeners.

### Challenges

One challenge of using AI is that its suggestions are not always exactly suitable for the current project. I still needed to test the suggested code and decide whether it worked correctly with my design and assignment requirements.

I also needed to make sure that I understood the code before using it. Some suggestions included more detail than was necessary for a simple portfolio, so I kept the implementation focused on the assignment requirements.

## Learning Outcomes

While completing this assignment, I learned more about:

- Structuring a webpage using semantic HTML.
- Separating HTML, CSS, and JavaScript into organized files.
- Using CSS Flexbox and Grid for page layouts.
- Using media queries to create responsive designs.
- Controlling how images behave at different screen sizes.
- Using HTML attributes for basic form validation.
- Using JavaScript event listeners to respond to user actions.
- Preventing the default behavior of a form using `event.preventDefault()`.
- Using Git and GitHub to manage and document changes to a project.
- Testing a website in multiple browsers and at different screen sizes.

Using AI as a learning assistant also helped me practice asking specific technical questions and evaluating the suggested solutions instead of automatically accepting them.

## Responsible Use & Modifications

I reviewed the AI-generated suggestions before adding them to my project and tested the website after making changes.

I modified suggestions when necessary to match my own portfolio and the assignment requirements. For example, I provided my own personal information, project descriptions, contact information, preferred colors, and design choices rather than using generic portfolio content.

During responsive testing, I noticed that the original image styling caused parts of the project images to disappear on smaller screens. I discussed the problem with ChatGPT, changed the image styling from `object-fit: cover` to `object-fit: contain`, and tested the result again.

I also tested the contact form myself to understand how the `required` and `email` input validation works. I tested the final website using both Safari and Google Chrome and resized the browser window to check its responsive behavior.

AI was used as an assistant during development, but I reviewed, modified, tested, and understood the implementation before including it in the final project.
